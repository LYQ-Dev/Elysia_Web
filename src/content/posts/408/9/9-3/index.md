## AI知识点带复盘
### 1. 磁盘系统核心结构考点
磁盘的核心组成包括盘片、磁头、磁道、扇区、柱面：
- 磁道：盘片表面同心圆状的记录区域
- 扇区：磁道上被划分的最小存储单元，是磁盘读写的基本单位
- 柱面：所有盘片上同一半径的磁道构成的圆柱面，是磁盘调度的核心操作单位
- 复盘易错点：曾混淆磁道与柱面的概念，明确柱面是跨盘片的磁道集合，是磁盘调度时无需移动磁头即可读取的连续区域。

### 2. 磁盘性能指标与计算公式
考研核心计算考点：
- 平均寻道时间$T_s$：磁头移动到目标磁道的平均耗时，需结合调度算法推导
- 平均旋转延迟$T_r$：磁盘旋转至目标扇区的平均耗时，通常为磁盘旋转一周时长的1/2，例如7200转磁盘的旋转周期为$60/7200≈8.33ms$，则$T_r≈4.17ms$
- 数据传输时间$T_t$：待传输数据量 / 磁盘外部传输速率
- 总存取时间$T = T_s + T_r + T_t$

### 3. 磁盘调度算法考点
整理7种考研高频调度算法的核心差异：
| 算法名称 | 核心逻辑 | 优缺点 | 适用场景 |
| ---- | ---- | ---- | ---- |
| FCFS | 按请求到达顺序处理 | 公平但寻道开销大 | 轻负载场景 |
| SSTF | 选择最短寻道距离的请求 | 寻道效率高，但易引发饥饿 | 中等负载场景 |
| SCAN（电梯算法） | 沿单方向移动磁头，处理沿途请求至端点后反向 | 避免饥饿，但两端请求等待时间长 | 高负载场景 |
| C-SCAN（循环扫描） | 磁头单向移动至端点后直接跳回起点，仅处理单向请求 | 调度更公平，消除两端等待差异 | 高并发负载场景 |
| LOOK | 简化SCAN，仅移动到当前方向最远请求即反向 | 减少不必要的寻道距离 | 实际生产场景 |
| C-LOOK | 简化C-SCAN，仅移动到当前方向最远请求即跳回起点 | 兼顾效率与公平性 | 主流生产与考研考点场景 |

### 4. 磁盘格式化与RAID基础
- 低级格式化：划分磁道扇区，写入磁盘控制器标识信息
- 高级格式化：创建文件系统，分配逻辑存储空间
- 常见RAID级别核心差异：RAID0无冗余读写最快但无容错；RAID1镜像冗余度最高但空间利用率仅50%；RAID5分布式校验，空间利用率$(n-1)/n$，兼顾性能与容错。
