## AI知识点带复盘
### 1. 简单插入排序
#### 核心思想
将待排序数组划分为**有序区**和**无序区**，初始时有序区仅包含数组第一个元素。依次遍历无序区的每个元素，从后往前与有序区元素比较，将大于当前元素的有序区元素向后移动一位，直到找到当前元素的插入位置，插入后扩大有序区范围，直至整个数组完全有序。
#### 标准实现（伪代码）
```plaintext
void insertSort(int arr[], int n) {
    for (int i = 1; i < n; i++) {
        int temp = arr[i]; // 缓存当前待插入元素
        int j = i - 1;
        // 从后往前遍历有序区，移动元素腾出插入位置
        while (j >= 0 && arr[j] > temp) {
            arr[j + 1] = arr[j];
            j--;
        }
        arr[j + 1] = temp; // 插入到正确位置
    }
}
```
#### 考研考点与特性
- 时间复杂度：最好情况（数组已有序）为$O(n)$，最坏情况（数组逆序）为$O(n^2)$，平均复杂度为$O(n^2)$
- 空间复杂度：$O(1)$，属于原地排序算法
- 稳定性：稳定排序，相等元素的相对位置不会发生改变
- 适用场景：数据量较小、数组基本有序的排序场景

### 2. 希尔排序
#### 核心思想
是简单插入排序的优化版本，通过**增量分组**降低插入排序的元素移动次数：
1.  选定初始增量`gap = n/2`（n为数组长度），将数组划分为`gap`个子序列，每个子序列的元素下标间隔为`gap`
2.  对每个子序列分别执行简单插入排序，让数组逐步趋近全局有序
3.  逐步缩小增量（`gap = gap // 2`），重复分组排序过程，直到`gap=1`，此时对整个数组执行一次简单插入排序，此时数组已基本有序，仅需少量移动即可完成最终排序
#### 标准实现（伪代码）
```plaintext
void shellSort(int arr[], int n) {
    for (int gap = n / 2; gap > 0; gap /= 2) {
        // 对每个分组执行插入排序
        for (int i = gap; i < n; i++) {
            int temp = arr[i];
            int j = i - gap;
            while (j >= 0 && arr[j] > temp) {
                arr[j + gap] = arr[j];
                j -= gap;
            }
            arr[j + gap] = temp;
        }
    }
}
```
#### 考研考点与特性
- 时间复杂度：依赖增量序列，采用希尔增量时平均复杂度为$O(n^{1.3}) \sim O(n^2)$，最坏复杂度仍为$O(n^2)$
- 空间复杂度：$O(1)$，属于原地排序算法
- 稳定性：不稳定排序，分组插入会改变相等元素的相对位置
- 适用场景：数据量较大的无序数组排序场景

### 3. 两种排序算法对比
| 维度         | 简单插入排序 | 希尔排序 |
|--------------|--------------|----------|
| 稳定性       | 稳定         | 不稳定   |
| 平均时间复杂度| $O(n^2)$     | $O(n^{1.3})$ |
| 核心优化点   | 无分组直接插入 | 增量分组减少移动次数 |
| 适用场景     | 小数据、基本有序 | 大数据集 |
