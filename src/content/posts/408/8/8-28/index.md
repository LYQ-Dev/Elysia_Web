## AI知识点带复盘
### 1. 虚拟存储的核心基础与概念
虚拟存储是408计组内存管理模块的核心考点之一，其核心目标是解决主存物理容量不足、CPU与主存速度不匹配的问题，通过操作系统+硬件协同的方式，为用户提供一个远大于实际物理主存的逻辑地址空间。其实现的理论基础是**程序局部性原理**，包含时间局部性（近期访问的数据/指令会被再次访问）与空间局部性（近期访问的存储单元附近的单元也会被高频访问）两类。

### 2. 虚拟存储的核心实现方案（考研高频对比考点）
考研常考三类虚拟存储管理方式，需精准掌握其差异：
| 管理方式 | 地址空间划分规则 | 核心优点 | 核心缺点 | 考研考察方向 |
| ---- | ---- | ---- | ---- | ---- |
| 页式虚拟存储 | 按固定大小划分为物理页与逻辑页 | 无外部碎片，内存利用率高 | 页表存储开销大，不便于按逻辑模块实现信息共享 | 地址变换流程、缺页中断处理、页面置换算法计算题 |
| 段式虚拟存储 | 按程序逻辑模块划分为段 | 便于按逻辑单元实现信息共享与权限保护，段长可动态调整 | 存在外部碎片，内存利用率偏低 | 段表结构、动态链接实现 |
| 段页式虚拟存储 | 先按逻辑分段，再将每段按固定大小分页 | 兼具前两者优点，既支持逻辑模块共享又无外部碎片 | 软硬件实现复杂度极高 | 多级地址变换完整流程 |

### 3. 考研高频考点拆解
#### （1）页面置换算法
此为408计组必考题型，需掌握5种经典算法的原理与缺页次数计算逻辑：
1.  **OPT最优置换算法**：置换未来最长时间不被访问的页面，为理论最优算法但无法实际落地，常作为性能对比基准
2.  **FIFO先进先出算法**：置换最早进入内存的页面，可能出现Belady异常（分配页框数增加，缺页次数反而上升）
3.  **LRU最近最少使用算法**：置换最近最久未被访问的页面，通过栈/链表实现，性能接近OPT，是考研考察频率最高的置换算法
4.  **Clock时钟置换算法**：基于参考位、修改位的近似LRU算法，分为简单Clock与改进Clock，适配硬件实现逻辑
5.  **工作集算法**：基于进程近期访问的页面集合（工作集）进行置换，可有效规避抖动问题

#### （2）抖动与工作集
- 抖动：指进程频繁触发缺页中断，导致CPU利用率急剧下降的异常现象，核心诱因是分配给进程的物理页框数不足
- 规避方案：增加进程分配页框数、采用局部置换策略、通过工作集模型动态调整页框分配量

#### （3）地址变换与TLB快表
虚拟地址到物理地址的转换依赖页表支撑，为加速变换流程引入**TLB快表**，TLB缓存常用页表项，命中时可直接获取物理页号，未命中则访问主存页表并同步更新TLB缓存。
